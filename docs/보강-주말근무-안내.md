# 보강 · 주말근무 슬랙 안내문 (전 직원용)

슬랙에 **그대로 붙여 넣는 원고**다. 슬랙 mrkdwn 문법(`*굵게*` · `_기울임_` · `• 목록`)으로 썼으므로
마크다운 제목(`#`)이나 표를 넣지 않는다 — 슬랙에서 렌더되지 않는다.

**붙여 넣는 방법**: 메시지 ①을 공지 채널에 올려 **상단 고정**하고, ②~④는 그 메시지의
**스레드 댓글**로 단다. 한 통에 다 넣으면 길어서 아무도 끝까지 읽지 않고,
슬랙 메시지 한 통은 4,000자에서 잘린다.

내용이 현재 시스템 설정(`OvertimePolicy`)과 맞는지 확인하고 올린다 — 배수·상한을 바꿨다면
메시지 ③도 함께 고쳐야 한다.

## ① 공지 채널 고정 메시지

```
📚 *보강 · 주말근무 신청 안내* (2026-08 개편)

보강과 주말근무를 슬랙에서 신청하고, *근무가 끝난 뒤 본인이 직접 실근무 시간을 확정*하는 방식으로 바뀌었습니다.
확정한 시간이 그대로 오버타임 수당 산정 근거가 되고, 급여명세서에 「보강 오버타임 산정 내역서」로 첨부됩니다.

*1. 신청하기 — 근무 전에 미리*

이 채널 상단에 고정된 버튼, 또는 슬랙 앱 홈 화면에서 누르세요.
• `보강계획 신청` — 보강을 하는 경우 (교수부)
• `주말근무 신청` — 교수부 외 직원이 주말에 근무하는 경우
• `내 신청 내역 · 실근무 확정` — 내가 낸 신청을 보고, 실근무 시간을 확정하는 곳

슬래시 명령으로도 됩니다: `/보강` · `/보강 주말` · `/보강 내역`

승인 절차는 없습니다. 제출하면 바로 등록되고, *보강은 보강캘린더에도 자동으로 올라갑니다*
(주말근무는 보강이 아니므로 보강캘린더에 올라가지 않습니다).

*2. 확정하기 — 근무가 끝난 다음날부터* ⚠️ 가장 중요합니다

*신청만 하고 확정하지 않으면 수당이 0원입니다.* 신청은 '이런 근무를 하겠다' 는 예고일 뿐이고,
실제로 몇 시부터 몇 시까지 일했는지를 확정해야 비로소 수당이 산정됩니다.

• *언제*: 근무가 끝난 *다음날 0시부터* 열립니다. 근무 중이나 근무 당일에는 열리지 않습니다.
• *어떻게*: 근무 다음날 오전에 확정 요청 DM 이 갑니다. DM 의 `실근무 시간 확정` 버튼을 누르거나,
  아무 때나 `내 신청 내역 · 실근무 확정` 에서 직접 하셔도 됩니다.
• *언제까지*: 근무한 달의 *다음 달 1일까지*입니다. (예: 8월 근무 → 9월 1일까지)
  그 뒤에는 급여 산정이 시작되어 관리자 확인이 필요합니다.
  ⚠️ *월말 근무는 시간이 촉박합니다* — 8월 31일에 근무하셨다면 9월 1일 하루뿐입니다.
  확정 요청 DM 이 오면 그날 안에 처리해 주세요.
• 확정한 뒤에도 마감 전까지는 몇 번이든 고칠 수 있습니다.

*3. 확정할 때 — 실제 시간을 그대로 적어 주세요*

신청할 때 적은 예정 시간이 미리 채워져 있지만, *그대로 제출하지 마시고 실제 시간으로 고쳐 주세요.*
일찍 끝났으면 끝난 시각을, 늦게까지 했으면 늦은 시각을 적으시면 됩니다.
줄여 적으실 필요도, 늘려 적으실 필요도 없습니다. 적으신 시간이 그대로 수당이 됩니다.

*4. 근무를 하지 않게 됐다면 — 그대로 두지 마세요*

보강·주말근무가 취소되거나 하지 않게 됐으면 `내 신청 내역 · 실근무 확정` 에서 그 건의
*미실시* 버튼을 눌러 주세요. 확정 화면 안의 `이 근무를 하셨나요?` 에서 *아니요* 를 골라도 됩니다.

• *근무 전에도 누를 수 있습니다.* 미리 내려 주시면 보강캘린더에서도 일정이 내려가고,
  확정 요청 DM 도 오지 않습니다.
• 수당은 발생하지 않습니다. 신청 기록과 사유는 남으니 없던 일이 되는 건 아닙니다.
• 잘못 눌렀거나 실제로는 근무하셨다면 관리자가 되돌릴 수 있습니다.

🧵 보강 종류별 수당 기준 · 수당 계산 방식 · 자주 묻는 질문은 이 글의 *스레드*에 이어집니다.
문의는 이 채널 또는 관리자에게 주세요.
```

## ② 스레드 댓글 — 보강 종류별 수당 기준

```
*[1/3] 보강 종류별 수당 기준*

신청할 때 고르는 '어떤 보강인가요?' 와 *근무한 날이 언제인가*에 따라 수당 처리가 달라집니다.

⚠️ *먼저 알아 두실 것* — 직전보강·내신의무보강이라도 *토요일·일요일·공휴일에 한 근무만*
자동으로 수당에 반영됩니다. *평일*에 한 보강은 결시보강과 마찬가지로 관리자가 건건이 판단합니다.
평일 보강은 원래 근무시간(14~22시) 안에서 이뤄지는 경우가 대부분이고, 그 시간은 이미 월 급여에
포함되어 있기 때문입니다. 평일인데 수당 반영이 필요한 사정이 있으면 관리자에게 말씀해 주세요.

• *직전보강* — 토·일·공휴일 근무는 수당 대상입니다. 확정만 하시면 그대로 산정됩니다.
  평일 근무는 관리자 판단을 거칩니다.

• *내신의무보강* — 위와 같고(토·일·공휴일 자동 반영), *내신 기간마다 10시간까지* 인정됩니다.
  10시간을 넘겨 신고하셔도 됩니다. 넘긴 시간이 없어지는 것이 아니라,
  10시간 안에서 *수당이 가장 많이 나오는 근무부터 채워* 배분합니다.
  (예: 토요일 7시간 · 일요일 7시간 → 배수가 높은 일요일 7시간을 먼저 채우고 토요일 3시간)
  그러니 실제로 하신 시간을 있는 그대로 적어 주시는 편이 유리합니다.

• *결시보강* — *기본적으로는 수당에 반영되지 않습니다.* 학생 사정으로 생긴 보강이라
  건건이 사정이 달라 관리자가 개별적으로 판단합니다.
  그래서 확정 버튼이 처음에는 열리지 않고, 대신 이런 안내가 보입니다:
  _"수당 반영 대상이 아니어서 실근무 확정이 열려 있지 않습니다."_
  수당 반영이 필요한 사정이 있으면 *관리자에게 말씀해 주세요.* 반영하기로 정해지면
  그때 확정 요청 DM 이 가고 버튼이 열립니다.

• *기타* — 결시보강과 같습니다. 기본 미반영이고 관리자가 판단합니다.

• *주말근무* — 수당 대상입니다. 교수부 외 직원이 주말에 근무하신 경우에 쓰는 별도 양식이라
  대상반·수강인원은 묻지 않고 담당 업무를 여쭙습니다.

_확정 버튼이 안 보이는데 수당을 받아야 하는 상황이라면, 잘못된 것이 아니라 관리자 판단을
기다리는 상태입니다. 편하게 문의해 주세요._
```

## ③ 스레드 댓글 — 수당이 계산되는 방식

```
*[2/3] 수당이 어떻게 계산되나요*

확정하신 시간에서 *원래 근무하기로 되어 있는 시간(소정근로시간)을 뺀 나머지*에 대해 산정합니다.

• *평일 소정근로시간 밖 · 토요일* → 통상시급 ×1.0 (가산 없음)
  우리 학원은 주 소정근로가 40시간에 못 미쳐서, 주 40시간 안쪽의 추가 근로는
  법정 가산(1.5배) 대상이 아닙니다. 일한 시간만큼 그대로 지급됩니다.
• *일요일 · 공휴일* → 통상시급 ×1.5 (8시간 초과분은 ×2.0)
  근로기준법상 휴일근로라 가산이 붙습니다.
• *소정근로시간 안에 이뤄진 보강* → 별도 수당이 없습니다.
  이미 월 급여에 포함되어 지급되고 있는 시간입니다.

계산 결과는 급여명세서 뒤에 「보강 오버타임 산정 내역서」로 첨부되어,
어느 날 몇 시간이 어떤 배수로 잡혔는지 건별로 확인하실 수 있습니다.

*계약 형태에 따라 다릅니다*

• *월급제 · 월급+인센티브* → 위와 같이 산정됩니다.
• *시급제* → 별도 오버타임 수당이 붙지 않습니다.
  보강·주말근무 시간도 출퇴근 기록에 그대로 잡혀 시급으로 지급되기 때문입니다
  (여기서 또 얹으면 같은 시간을 두 번 받게 됩니다).
  *신청은 그대로 해 주세요* — 일정 공유와 근무 기록을 위해 필요합니다.
• *완전비율제(위탁)* → 근로기준법상 근로자가 아니라 시간 단위 수당이 적용되지 않습니다.
  마찬가지로 일정 공유 목적으로 신청은 해 주세요.

_배수와 상한은 회사 지급 조건 설정에 따르며, 바뀌면 다시 공지드립니다._
```

## ④ 스레드 댓글 — 자주 묻는 질문

```
*[3/3] 자주 묻는 질문*

*Q. 신청을 깜빡했는데 이미 보강을 했습니다.*
지금이라도 신청해 주세요. 지난 날짜로도 등록됩니다. 등록 후 바로 확정하실 수 있습니다.

*Q. 확정 요청 DM 이 안 왔습니다.*
네 가지 경우입니다. ① 아직 근무 다음날 오전이 되지 않았거나 ② 결시보강처럼 기본 미반영
종류라 관리자 판단을 기다리는 중이거나 ③ *평일에 한 보강*이라 마찬가지로 관리자 판단을
기다리는 중이거나 ④ 슬랙 계정이 직원 정보에 연결되어 있지 않은 경우입니다.
DM 을 기다리지 않고 `내 신청 내역 · 실근무 확정` 에서 직접 확정하셔도 됩니다.

*Q. 예정 시간과 실제 시간이 많이 다릅니다. 그대로 적어도 되나요?*
네, 그대로 적어 주세요. 예정은 예정일 뿐이고 실제 근무한 시간이 기준입니다.

*Q. 확정했는데 시간을 잘못 적었습니다.*
마감(다음 달 1일) 전이면 같은 버튼을 다시 눌러 고치시면 됩니다.
마감이 지났으면 관리자에게 말씀해 주세요.

*Q. 확정한 시간이 관리자에 의해 바뀌었습니다.*
바뀐 경우 자동으로 DM 이 갑니다. 내용이 사실과 다르면 바로 말씀해 주세요.
근무 사실 확인이 필요한 경우 최종 판단은 관리자에게 있습니다.

*Q. 보강이 취소됐습니다 / 하지 않게 됐습니다.*
`내 신청 내역 · 실근무 확정` 에서 그 건의 *미실시* 를 눌러 주세요. 근무 전에도 누를 수 있습니다.
누르면 보강캘린더에서 일정이 내려가고 수당도 잡히지 않습니다. 확정 마감이 지난 뒤이거나
이미 확정해 둔 건이면 관리자에게 말씀해 주세요.

*Q. 자정을 넘겨 끝났습니다.*
종료 날짜를 다음날로 골라 주시면 됩니다. 이 경우 확정은 *종료일 기준 다음날*부터 열립니다.

*Q. 주말근무인데 보강캘린더에 안 보입니다.*
정상입니다. 보강캘린더는 보강 일정만 담습니다. 주말근무는 HR 시스템에만 기록되고
수당 산정에는 동일하게 반영됩니다.
```
