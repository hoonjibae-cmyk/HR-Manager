# 반배정 답변 알림 · HR v1.60.0 / OMR v1.63.0

1. OMR의 반편성 요청자가 HR 사번으로 연결되어 있으면 그 직원이 담당자로 저장됩니다.
2. `#반배정`의 봇 요청 스레드에 **재직 중인 경영지원 또는 교수부장**이 댓글을 달면 담당 직원에게 학생명·작성자·댓글·원문 링크가 DM으로 전달됩니다. 교육운영팀, 일반 강사, 조교 및 봇 댓글은 전달하지 않습니다. 휴가 승인자 설정과는 별개의 권한입니다.
3. 담당 직원이 DM의 **확인 완료**를 누르면 DM과 원래 요청에 확인 완료가 표시됩니다. 후속 댓글은 별도로 전달되고 다시 확인 대기로 표시됩니다.
4. 담당자가 없는 요청은 원래 메시지의 **담당 직원 지정 · 변경**으로 연결합니다. 이 변경도 경영지원·교수부장만 가능합니다. 이름 유사도로 직원을 추측하지 않습니다.

## Slack 앱 활성화

기존 **유쌤 알리미** 앱을 그대로 사용합니다. 새 앱이나 토큰을 만들지 않습니다.

- OAuth Bot Scope: `channels:history` 추가 (공개 채널 댓글 Events API 수신에 필요).
- Event Subscriptions: 기존 `https://hr.yussam.com/api/slack/events`, 기존 `app_home_opened` 유지, `message.channels` 추가.
- Interactivity: 기존 `https://hr.yussam.com/api/slack/interactivity` 유지.
- 기존 봇을 `#반배정`에 초대합니다. 비공개 채널 권한은 추가하지 않습니다.
- 새 Scope가 필요한 경우 관리자가 권한을 확인한 뒤 기존 앱을 재설치합니다.
- 소스 매니페스트와 `/api/slack/manifest`에도 위 설정이 반영되어 있습니다. 기존 앱 설정을 전체 교체하지 말고 필요한 항목만 추가하세요.
- HR 관리자 로그인 후 `/api/slack/placement-health`에서 실제 OAuth scope, 큐 수, 마지막 수신 이벤트를 확인할 수 있습니다. 이 엔드포인트는 토큰을 반환하지 않습니다.

## 중복·오류 처리

- Slack 서명 검증 후 이벤트를 DB에 저장하고 빠르게 응답합니다. 백그라운드 처리와 분 단위 인증된 cron이 이어받습니다.
- 같은 댓글·같은 수정 버전은 한 번만 전달합니다. 실제로 수정된 댓글은 새 버전으로 전달합니다.
- 발송 여부가 불명확한 네트워크 단절은 `uncertain`에 남겨 자동 재발송하지 않습니다. 담당자가 원문과 DM을 확인해야 합니다.
- 확인 상태는 서버 DB에 남고 Slack 메시지 업데이트 실패 시 cron이 재시도합니다.
- 기존 요청은 새 댓글이 달릴 때 원래 봇 이미지 토큰으로 OMR 요청자를 찾아 연결합니다. 과거 댓글을 일괄 재발송하지 않습니다.
- 담당자 변경 시 이전 수신자는 더 이상 확인 처리할 수 없습니다. 새 담당자에게 전달합니다.
- 댓글은 알림만 전달하며, 댓글 내용으로 반편성 데이터를 자동 변경하지 않습니다.
- Student Card 코드·배포는 변경하지 않습니다.
