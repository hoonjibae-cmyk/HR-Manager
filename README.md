# 유쌤에듀 HR 관리 프로그램 (Yoossam HR)

주식회사 유쌤에듀의 인사·급여·연차·문서 업무를 하나로 통합한 웹 애플리케이션입니다.
기존 엑셀(ERP)로 처리하던 근로계약서·서약서·급여명세서 작업을 대체하고,
**연차 관리 · 각종 증명서 발급 · 급여명세서 자동 이메일 발송 · 슬랙 연차 신청/승인**
기능을 새로 제공합니다.

> 기술스택: **Next.js 14 (App Router) · TypeScript · Prisma · PostgreSQL(Supabase) · puppeteer-core + @sparticuz/chromium(PDF) · nodemailer · Slack API**
> 배포: **Vercel + Supabase** (서버리스, 상시 운영) — [docs/DEPLOY.md](docs/DEPLOY.md)

|---|---|

| **급여 산정** | 통상시급·주휴수당·209시간 환산·4대보험(국민연금·건강·장기요양·고용)·근로소득 간이세액표·지방소득세·사업소득 3.3% 자동 계산. 인센티브(학생수 초과분), 완전비율제(반 매출×%) 지원 |
| **급여명세서** | 4대보험형/사업소득(3.3%)형 명세서 PDF 발급 및 **이메일 발송** |
| **자동 발송** | 지정한 요일·시간에 급여명세서를 직원 이메일로 **예약 자동 발송** (내부 스케줄러 또는 외부 크론) |

계약 구조(1년 단기 → 1년 추가 → 정규 / 또는 1년 단기 → 정규), **3개월 수습기간**(2026-11 이후 신규 계약. 급여 100%, 업무 적격성 판단 조항 — 그 전 계약은 2개월 그대로)이 계약서에 반영됩니다.

## 빠른 시작

**상시 운영(권장)** 은 Supabase + Vercel 배포입니다 → **[docs/DEPLOY.md](docs/DEPLOY.md)** (20~30분).

로컬 개발/체험:

```bash
# 1) 의존성 설치
npm install

# 2) 환경변수 설정
cp .env.example .env
#   → .env 에 PostgreSQL 접속정보(DATABASE_URL, DIRECT_URL)를 입력.
#     Supabase 무료 DB를 쓰거나, 로컬 Postgres를 사용하세요(.env.example 예시 참고).
#     PORTAL_ORIGIN, HR_SSO_SECRET, SESSION_SECRET을 설정하세요.

# 3) 데이터베이스 스키마 생성 + 기초 데이터 시딩
npm run db:push      # Postgres 스키마 생성
npm run seed         # 회사정보·4대보험요율·간이세액표·공휴일·직원(데모) 시딩

# 4) 개발 서버 실행
npm run dev
#   → http://localhost:3000  (포털의 경영지원 계정 확인 후 입장)
```

> **가장 쉬운 체험**: GitHub 저장소 → `Code ▸ Codespaces ▸ Create` 하면
> PostgreSQL·Chromium·시딩까지 자동 준비됩니다(설치 불필요). 이후 `npm run dev`.

> **자체 서버(VPS) 운영 시**: `TZ=Asia/Seoul ENABLE_SCHEDULER=true npm run build && npm start`
> (내부 스케줄러가 예약 발송을 처리. Vercel 배포 시에는 Vercel Cron 사용 — DEPLOY.md 참고)

## 외부 연동 (이메일 · 슬랙)

급여명세서 이메일 발송과 슬랙 연차 신청은 유쌤에듀 계정의 **SMTP 정보**와 **슬랙 앱 토큰**이 필요합니다.
설정 방법은 **[docs/SETUP.md](docs/SETUP.md)** 를 참고하세요. 토큰만 `.env`에 넣으면 코드 수정 없이 바로 동작합니다.

- **SMTP**: `SMTP_HOST/PORT/USER/PASS`, `MAIL_FROM`
- **슬랙**: `SLACK_BOT_TOKEN`, `SLACK_SIGNING_SECRET`, `SLACK_APPROVAL_CHANNEL`, `SLACK_APPROVERS`
- **스케줄러**: 상시 구동 서버는 `ENABLE_SCHEDULER=true`. 서버리스 배포는 외부 크론이 `/api/cron?secret=...` 호출.

## 급여 계산 근거 (요약)

- **통상시급(월급제)** = 월 기본급 ÷ 월 소정근로환산시간, 환산시간 = (주 소정근로 + 주휴) × 4.345.
  경업금지 보상금이 있으면 **월 지급 총액에서 보상금을 뺀 금액**으로 낸다(포괄임금 약정 시간외·야간도 같은 통상시급)
- **통상시급(비율제 근로계약)** = 그 달 이 회사가 지급하는 임금(비율급 — 식대 포함) ÷ 같은 환산시간.
  **경업금지 보상금은 넣지 않는다**(근로의 대가가 아니라 경업금지 의무의 대가 — 근로계약서 제4조 ③ 이 그렇게 적고
  명세서 각주가 같은 식을 금액 그대로 적는다). 상한이 걸린 달의 기준은 상한액 − 보상금이다
- **주휴시간** = 주 소정근로 < 15h → 0, 아니면 min(주소정/5, 8)
- **4대보험(근로자부담, 기본 2025)**: 국민연금 4.5% · 건강 3.545% · 장기요양 12.95%(건강보험료 대비) · 고용 0.9%
- **근로소득세**: 근로소득 간이세액표(제189조) 구간·부양가족수 조회, 지방소득세 = 소득세 10%
- **사업소득**: 지급총액 3.3%(소득세 3% + 지방소득세 0.3%)
- **인센티브** = (학생수 − 기준) × 1명당 금액, **완전비율제** = 반 매출 × 비율(%)
  — 위탁(사업소득 3.3%) 또는 **근로계약(4대보험)**. 근로계약이면 근로소득 상한(예: 월 500만원)을 둘 수 있고,
  넘는 비율급은 별도 사업장이 사업소득(3.3%)으로 지급한다(명세서·세무 자료·이체 파일이 지급처별로 갈리고,
  계약서 발급 때 그 사업장 명의의 용역위탁계약서가 함께 나간다). 경업금지 보상금은 매출 × 비율로 별도 지급(위탁·근로 모두) —
  근로계약이면 상한은 비율급과 보상금의 합에 걸린다. 근로계약의 식대·차량유지비(비과세)는 월급제처럼 비율급 **안에** 든
  금액이다(얹지 않는다 — 지급액은 그대로, 과세 대상만 준다)
- **사업소득용 계좌**: 근로소득(이 회사)과 사업소득(별도 사업장)을 함께 받는 직원은 받는 통장도 가를 수 있다 —
  직원 정보의 급여 이체 계좌에 **사업소득용 계좌**(은행·계좌번호·예금주)를 넣으면 별도 사업장 이체 파일이 그 계좌로
  나간다(급여·퇴직유보금 계좌와 별개. 비우면 급여 계좌로 나가고 파일을 받을 때 알린다. 계좌번호는 암호화 저장)
- **경업금지 보상금은 임금으로 다루지 않는다**: 근로의 대가가 아니라 경업금지 의무의 대가라 통상시급(연장·휴일·야간·
  연차수당의 기준)과 퇴직급여 산정기준에 넣지 않는다(월급제·비율제 근로계약 모두). 계약서 제4조가 그렇게 적는다
- **경업금지 보상금의 세무 처리**: 기본은 과세 급여에 넣어 4대보험·근로소득세를 잰다. 설정 → 회사 정보의
  「경업금지 보상금을 비과세로 처리」를 켜면 근로계약(4대보험)의 보상금을 식대처럼 비과세로 본다(위탁 3.3% 는 무관).
  세무대리인 확인 뒤에 켤 것 — 과세로 판정되면 추징 대상이다
- **무급휴직**: 그 달 지급 비율 = (그 달 재직 역일수 − 무급휴직 역일수) ÷ 그 달 역일수. 주말·공휴일도 날 수에 든다
  (11/1~11/15 무급휴직과 11/16 입사가 같은 금액). 기본급·월 정액 수당·포괄임금 약정분에 걸리고 통상시급은 그대로다.
  완전비율제는 매출 기준이라 일할하지 않고, 시급제는 출퇴근 기록의 실근로시간으로 지급한다. 한 달을 통째로 쉬어도
  재직자라 급여 시트에 0원 행으로 남는다. **이미 산정해 둔 달은 「급여 일괄 산정」을 다시 눌러야 반영된다** —
  급여 화면이 그 행을 「무급휴직 미반영」으로 띄우고, 세무 자료·이체 파일을 받을 때도 알린다.
  퇴직급여는 그 달 급여에서 산정하므로 함께 줄어든다(⚠ 육아휴직·출산전후휴가처럼 법으로 보호되는 휴직은 그 기간을
  빼고 부담금을 산정해야 하므로, 그런 달은 퇴직급여 화면에서 기준급여를 직접 지정한다)
- **유급휴직·휴업**: 같은 카드에서 구분을 고른다. 정상 급여는 무급휴직과 똑같이 일할하고(쉰 날은 빠진다), 그 기간의
  급여는 따로 서는 지급 항목으로 나간다 — **휴업수당·유급휴직 급여 = 원급여 × 지급 비율**, 원급여 = 월 기준액 ×
  그 기간 역일수 ÷ 그 달 역일수. 월 기준액은 계약상 월 급여(월 지급 총액 + 직책수당. 시급제는 시급 × 월 소정·주휴시간 +
  월 정액 수당)이고 **경업금지 보상금은 넣지 않는다**(근로의 대가가 아니다 — 보상금은 근로계약서 제8조대로 쉰
  기간만큼 일할로 빠져, 보상금이 있는 직원은 100% 여도 그 몫만큼 평소보다 적다). 보상금이 없으면 비율 100% 가
  휴직 없는 달과 같은 금액이다. **금액을 직접 넣을 수도 있다** — 그 기간 전체의 금액이고 달을 걸치면 날 수대로
  나뉜다(완전비율제는 원급여가 없어 금액으로만). 전액 과세로 잡고 퇴직급여 산정기준에 든다.
  ⚠ 근로기준법 §46 의 휴업수당 기준은 **평균임금**의 70% 다 — 앱의 비율은 원급여(계약 월 급여) 대비라 연장수당·
  상여가 있던 사람은 법정 기준보다 적을 수 있다. 평균임금으로 계산한 금액이 있으면 금액으로 넣는다(70% 미만이면
  화면이 알린다 — 막지는 않는다)
- **비율 지급의 산정 기준**: 건마다 둘 중에서 고른다(기본은 역일수 기준).
  - **역일수 기준** — 위의 식 그대로(원급여 = 월 기준액 × 그 기간 역일수 ÷ 그 달 역일수). 주휴일·휴일 몫이 들어 있어
    100% 면 평소 급여와 같다.
  - **소정근로일 기준** — 통상임금으로 센다: **원급여 = 통상시급 × 1일 환산시간(주 소정근로시간 ÷ 5) × 그 기간의
    평일(월~금) 수**. 통상시급은 급여 엔진의 통상시급과 같은 값(월 급여 ÷ 월 유급시간)이고 **반올림하지 않고 곱해
    원급여에서 한 번 반올림**한다. 예) 월 3,200,000원 · 주 18시간(월 유급 93.852시간 · 1일 3.6시간) · 70%:
    11/7~11/30 평일 16일 → 3,200,000 ÷ 93.852 × 3.6 × 16 = 1,963,943원 × 70% = **1,374,760원**.
    평일에 든 공휴일은 세고 주휴일·토요일 몫은 넣지 않는다 — 100% 여도 평소 한 달 급여보다 적다. 근로시간표가 있어야 한다.
    ⚠ 사용자 귀책 휴업이면 휴업기간에 든 주휴일(유급휴일)도 휴업수당 산정에 포함해야 한다는 행정해석이 있으니
    확인할 것(주휴일 몫이 들어가는 쪽은 역일수 기준)
  - 어느 기준이든 **정상 급여의 일할은 역일수**다(기준은 쉰 날의 돈만 정한다)
- 공제액은 10원 미만 절사(엑셀 ROUNDDOWN 동일 — 요율 곱셈의 부동소수점 오차를 걷어낸 뒤 절사)
