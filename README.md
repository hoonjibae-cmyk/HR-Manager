# 유쌤에듀 HR 관리 프로그램 (Yoossam HR)

㈜유쌤에듀의 인사·급여·연차·문서 업무를 하나로 통합한 웹 애플리케이션입니다.
기존 엑셀(ERP)로 처리하던 근로계약서·서약서·급여명세서 작업을 대체하고,
**연차 관리 · 각종 증명서 발급 · 급여명세서 자동 이메일 발송 · 슬랙 연차 신청/승인**
기능을 새로 제공합니다.

> 기술스택: **Next.js 14 (App Router) · TypeScript · Prisma · SQLite · Playwright(PDF) · nodemailer · Slack API**

---

## 핵심 기능

| 영역 | 내용 |
|---|---|
| **직원 관리** | 인적사항·소속·근로형태·주간 근로시간표·임금 정보 CRUD. 4대보험/사업소득, 월급제/시급제/인센티브/완전비율제 지원 |
| **급여 산정** | 통상시급·주휴수당·209시간 환산·4대보험(국민연금·건강·장기요양·고용)·근로소득 간이세액표·지방소득세·사업소득 3.3% 자동 계산. 인센티브(학생수 초과분), 완전비율제(반 매출×%) 지원 |
| **급여명세서** | 4대보험형/사업소득(3.3%)형 명세서 PDF 발급 및 **이메일 발송** |
| **자동 발송** | 지정한 요일·시간에 급여명세서를 직원 이메일로 **예약 자동 발송** (내부 스케줄러 또는 외부 크론) |
| **연차 관리** | 근로기준법 제60조 기준 자동 산정(1년 미만 월 1일·최대 11일 → 1년 15일 → 2년마다 +1, 상한 25일). 발생·사용·소멸(FIFO)·잔여 추적 |
| **슬랙 연차** | 직원이 슬랙 `/연차` 로 신청 → 관리자 채널에서 버튼 승인/반려 → 프로그램에 자동 반영. `/연차 조회` 로 잔여연차 셀프 확인 |
| **문서 발급** | 신규입사 패키지(근로계약서+복무서약서+개인정보동의서+임금공제동의서 **1 PDF**), 재계약서, 재직/경력 증명서 |
| **재계약 관리** | 대시보드에서 60일 내 계약 만료 직원 표시 → 변경된 조건으로 재계약서 발급 |

계약 구조(1년 단기 → 1년 추가 → 정규 / 또는 1년 단기 → 정규), **2개월 수습기간**(급여 100%, 업무 적격성 판단 조항)이 계약서에 반영됩니다.

## 빠른 시작

```bash
# 1) 의존성 설치
npm install

# 2) 환경변수 설정
cp .env.example .env
#   → .env 파일에서 ADMIN_PASSWORD, SESSION_SECRET 등을 변경하세요.

# 3) 데이터베이스 생성 + 기초 데이터 시딩
npm run db:push      # SQLite 스키마 생성
npm run seed         # 회사정보·4대보험요율·간이세액표·공휴일·직원(데모) 시딩

# 4) 개발 서버 실행
npm run dev
#   → http://localhost:3000  (기본 비밀번호: .env 의 ADMIN_PASSWORD)

# 프로덕션 실행
npm run build && npm start
```

> **한국 시간대**: 예약 자동발송이 정확히 동작하려면 서버 시간대를 KST로 설정하세요.
> `TZ=Asia/Seoul npm start`

### 주요 스크립트

| 명령 | 설명 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` / `npm start` | 프로덕션 빌드/실행 |
| `npm run seed` | 기초 데이터 시딩 |
| `npm run db:reset` | DB 초기화 후 재시딩 |

| `npm test` | 급여·연차 엔진 단위 테스트 |

## 외부 연동 (이메일 · 슬랙)

급여명세서 이메일 발송과 슬랙 연차 신청은 유쌤에듀 계정의 **SMTP 정보**와 **슬랙 앱 토큰**이 필요합니다.
설정 방법은 **[docs/SETUP.md](docs/SETUP.md)** 를 참고하세요. 토큰만 `.env`에 넣으면 코드 수정 없이 바로 동작합니다.

- **SMTP**: `SMTP_HOST/PORT/USER/PASS`, `MAIL_FROM`
- **슬랙**: `SLACK_BOT_TOKEN`, `SLACK_SIGNING_SECRET`, `SLACK_APPROVAL_CHANNEL`, `SLACK_APPROVERS`
- **스케줄러**: 상시 구동 서버는 `ENABLE_SCHEDULER=true`. 서버리스 배포는 외부 크론이 `/api/cron?secret=...` 호출.

## 급여 계산 근거 (요약)

- **통상시급(월급제)** = 월 기본급 ÷ 월 소정근로환산시간, 환산시간 = (주 소정근로 + 주휴) × 4.345
- **주휴시간** = 주 소정근로 < 15h → 0, 아니면 min(주소정/5, 8)
- **4대보험(근로자부담, 기본 2025)**: 국민연금 4.5% · 건강 3.545% · 장기요양 12.95%(건강보험료 대비) · 고용 0.9%
- **근로소득세**: 근로소득 간이세액표(제189조) 구간·부양가족수 조회, 지방소득세 = 소득세 10%
- **사업소득**: 지급총액 3.3%(소득세 3% + 지방소득세 0.3%)
- **인센티브** = (학생수 − 기준) × 1명당 금액, **완전비율제** = 반 매출 × 비율(%)
- 공제액은 10원 미만 절사(엑셀 ROUNDDOWN 동일)

> 요율은 **설정 화면에서 매년 수정** 가능합니다. 기본값은 2025년 기준입니다.

## 데모 데이터 & 개인정보

시딩되는 직원 데이터는 원본 엑셀의 **조직/직책/급여형태/근로시간 구조**를 사용하되,
**이름·주민번호 등 개인정보는 실제 값이 아닌 가명**입니다 (원본 엑셀에 개인정보가 비어 있었음).
실제 운영 시 `직원 관리`에서 실제 정보로 교체하세요.

## 보안 유의사항

- 배포 전 `.env`의 `ADMIN_PASSWORD`, `SESSION_SECRET`, `CRON_SECRET`을 반드시 변경하세요.
- 주민등록번호 등 민감정보는 운영 환경에서 암호화 저장을 권장합니다(현재는 평문 저장).
- `dev.db`(SQLite)와 `.env`, `storage/`(생성 PDF)는 Git에 커밋되지 않습니다.
